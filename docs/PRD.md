# 社区团购产品需求

## 唯一业务流程

1. 运营在后台配置服务区域、自提点、商品与团期。一团绑定一个固定自提点，开售后不得更换。
2. 消费者在微信小程序下单，通过微信 JSAPI 支付。
3. 截单后，系统按已付款订单生成拣货装袋标签；运营人工备货、约车并登记运输信息。
4. 点位负责人使用网页工作台逐商品确认到货。短少按支付时间升序、订单号升序生成确定性分配草案，由运营确认。
5. 正常商品可分次领取。点位负责人按本点权限和六码取货码核销，重复请求必须幂等。
6. 财务只执行运营已确认的全额或部分原路退款。
7. 领取截止为确认到货后的第 3 个自然日 23:59:59（中国时区）；截止时刻起禁止普通核销，由运营延期、退款或报损。
8. 品质售后按每次领取凭证逐商品计算，仅限该次确认领取后未满 24 小时，满 24 小时即截止；分次领取互不延长此前商品的期限。

## 人员与权限

- `SUPER_ADMIN`：系统配置与紧急代办。
- `OPERATOR`：区域、点位、商品、团期、运输、差异决定。
- `CUSTOMER_SERVICE`：客户联系和品质售后受理。
- `FINANCE`：已批准退款与账本。
- `PICKUP_MANAGER`：仅网页点位工作台，且只访问已授权自提点。
- `USER`：消费者小程序。

点位负责人由后台创建账号、激活和分配点位。角色、状态或点位权限变化后，现有会话立即失效。

## 生产外部能力

- 微信小程序真实登录。
- 微信支付商户直连 JSAPI 支付。
- 全额与部分退款、支付和退款回调签名校验及幂等处理。
- 微信订阅消息；失败进入可追踪的人工联系队列。

区域、点位、商品、团期和运输信息不得写死在代码或生产迁移中。预计订单量不是业务配置。
