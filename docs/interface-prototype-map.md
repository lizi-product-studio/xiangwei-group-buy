# 团购平台界面与履约原型

## 已确认的业务基准

平台统一采购、定价和开团；运营必须在团期开售前，为该团期绑定服务区域内一个已启用的固定自提点。用户在下单前即可看到并确认该点的名称、地址与预计到货窗口，随后立即支付。截团后，运营只推进备货、约车、发车与到货，不再为已有订单更换领取地点；到货确认后，订单开放取货码。

“收货区域”是长期可开放的服务范围；“固定自提点”是经审核、启用后可被团期绑定的领取点。配送计划记录该固定点的到货窗口和履约进度，不是截团后临时决定地点的机制。

## 小程序

| 页面 | 用户看到的内容 | 关键动作 |
| --- | --- | --- |
| 团购首页 | 收货区域、当前固定自提点、本团商品和团期 | 选择自提点、查看商品、加购 |
| 收货区域与自提点选择 | 已开放区县、已启用固定自提点与未开放提示 | 选择区域和自提点、登记开通意向 |
| 商品详情 | 截单时间、固定自提点名称/地址、预计到货窗口 | 立即购买、加入购物车 |
| 购物车 / 结算 | 仅同团期同固定自提点商品；地点与时间再次确认 | 确认并支付 |
| 我的订单 / 订单详情 | 已确认的固定地点、备货/运输/到货状态和到货窗口 | 支付、到货后查看取货码 |
| 我的 | 当前收货区域与固定自提点、订单分类、领取说明 | 切换区域或自提点、联系客户 |

## 运营平台

| 页面 | 运营动作 |
| --- | --- |
| 工作台 | 聚合待绑定自提点、待约车、可建批次、运输中待到货任务 |
| 团期 | 草稿选择收货区域、商品和已启用固定自提点；绑定后方可开售 |
| 收货区域 | 开放可收单区县；支持按全国行政区划逐步增加 |
| 配送与领取 | 更新固定自提点到货窗口 → 登记货拉拉预约 → 创建批次 → 确认发车 → 确认到货 |
| 订单 | 查看订单所属区域、固定自提点、履约状态和资金状态 |
| 结算 / 留痕 | 保留退款、结算及地点、车辆、到货相关操作记录 |

## 状态与权限

配送计划状态：`待绑定固定自提点 → 固定点已确认 → 已预约车辆 → 运输中 → 已到货`。其中“待绑定”仅允许团期草稿阶段存在，不能开售或下单。

- 消费者：匿名团期接口只读取消费者所需的固定地点、到货窗口与履约状态；不能看运营备注、联系人、司机、车辆或约车凭证。
- 运营 / 履约：维护地点、预约车辆、发车和到货。
- 现场核销人员：仅在本人已获授权、点位仍启用且计划已到货时，使用配送计划 ID 查询本点订单并校验取货码。

## 上线前仍需外部确认

微信订阅消息（到货窗口更新和到货提醒）、地图选点、真实货拉拉接口、实际支付资质、逾期未领取规则及固定自提点不可变更后的退款规则。
