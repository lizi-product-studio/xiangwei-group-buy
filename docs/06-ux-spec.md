# UX specification

## Navigation

| Role | Surface / default landing | Primary pages | Exit / recovery |
|---|---|---|---|
| USER | 小程序首页；我的作为账户入口 | 首页、团期、购物车、订单、消息、售后、意向 | 登录取消返回来源；失效清空前账号数据 |
| PICKUP_MANAGER | Web 点位工作台 | 到货、核销 | 无其他后台菜单；403 留在安全页 |
| OPERATOR | Web 工作台 | 商品、团期、订单、配送、点位、售后、治理 | 错误保留当前对象并可重试 |
| CUSTOMER_SERVICE | Web 售后与异常 | 售后、治理、必要订单 | 无财务/配置入口 |
| FINANCE | Web 财务 | 待退款、人工挂起、账本 | 无运营修改入口 |
| SUPER_ADMIN | Web 设置 | 员工、权限、审计、紧急代办 | 敏感动作二次确认 |

## User flows

| Journey | Main steps | Success | Alternate / error | Return / recovery |
|---|---|---|---|---|
| 参团 | 选区域点位→团期→购物车→结算→支付 | 订单显示已支付待截单 | 无覆盖转意向；库存冲突刷新；支付取消保留订单 | 返回订单详情继续支付或查看 |
| 截单履约 | 影响预览→截单→备货运输→到货→差异 | 可生成取货码 | 首次未成团顺延；第二次取消退款；运输异常显示责任 | 用户订单显示新时间/退款进度 |
| 领取 | 出示六码→逐项核销→可再次领取 | 累计领取/完成 | 错码、跨点、重复、截止时刻明确拒绝 | 仍可领取量保持可见 |
| 售后 | 订单入口→选择多商品行→提交→受理/决定/退款 | 案件 RESOLVED | 24h/数量/重复错误；拒绝显示原因 | 回订单详情和消息 |
| 通知 | 查看站内消息→分组授权微信提醒 | 七类语义映射完成 | 拒绝仍有站内消息；失败转人工证据 | “继续授权”处理剩余模板 |
| 数据权利 | 意向页查看→更正 NEW/撤回 | 列表更新 | 已处理更正转客服；撤回说明保留例外 | 保留状态与审计 |
| 自提点定位（OPERATOR/SUPER_ADMIN） | 选择服务区域→查看只读行政路径→输入详细地址并选择 POI→地图确认/拖动图钉→保存 | 点位绑定所选服务区域，地图结果仅完成行政路径相容核验 | 搜索、地图或逆编码失败均安全拒绝位置写入；疑似重复需明确确认 | 返回点位列表；编辑默认保留历史位置，只有触发事件才进入定位流程 |

## Page behavior

- 每页一个主任务；提交中禁用；成功先采用写接口真实状态，再刷新。
- 加载新身份前清空旧身份数据；所有同身份重复刷新使用 generation，迟到 data/loading/error 均不得覆盖新结果。
- destructive/sensitive：团期取消、顺延、点位停用、人工通知完成、意向撤回均提供原因/证据与二次确认。
- 错误说明发生了什么和下一步；正常空状态不能被网络错误冒充。

## 自提点定位规格（P1 冻结基线）

### 事实来源与保存条件

- **CONFIRMED**：仅 OPERATOR 和 SUPER_ADMIN 可以创建或编辑自提点位置；消费者、点位负责人和其他内部角色没有该入口。
- **CONFIRMED（用户批准方向）**：先选择 `serviceAreaId`。系统从该服务区域的 `regionCode` 和行政区目录展示只读的省/市/区路径；运营不能再填写一组独立的省市区来决定归属。
- **DEFAULT_ASSUMPTION / BLOCKING_UNKNOWN**：本轮把 ServiceArea 作为一个行政目录节点，地图校验只显示“行政路径相容/不相容”，不显示或暗示“已在实际服务范围内”。同区错图钉、错门牌、边界相邻和不可通行地点仍是未消除的运营风险；若业务范围不是单一目录节点，停止实施并回到需求/架构决策。
- **EVIDENCE_INFERRED**：地图当前使用高德瓦片，位置坐标按 GCJ-02 传递；经纬度不是面向运营的表单字段。地图可显示精度，但不得要求运营理解或手工录入数值。
- **CONFIRMED（用户批准方向）**：新建、位置变更或 INACTIVE→ACTIVE 的保存条件是：已选服务区域、名称和必要运营字段有效、地址/图钉存在、获批准适配器返回可映射的规范化目录节点且路径相容；任一项不满足时“保存/启用”保持不可用或返回明确字段错误。位置核验只在本次请求发生，不产生持久“已核验”展示。

### 新建与重新定位流程

| 状态 | 运营动作/界面反馈 | 可执行下一步 | 保存条件 |
|---|---|---|---|
| 初始 | 先选服务区域，立即展示“行政目录：省/市/区”只读摘要；未选区域时地址搜索与地图确认不可开始 | 选择已有服务区域 | 不可保存 |
| 输入地址 | 输入详细地址后显示搜索中；候选 POI 列表不自动替运营选择第一项 | 选择候选，或继续补充地址 | 不可保存，直到位置确认 |
| POI 命中 | 选中候选后更新图钉和建议展示地址；展示“请检查图钉是否是实际自提位置”与“正在核验行政路径” | 确认或拖动图钉 | 需完成行政路径核验；通过不表示门牌/可达性已证明 |
| POI 无结果 | 显示“未找到该地址。可补充门牌/乡镇名称，或在地图上点选实际位置。”；已输入内容保留 | 修改文字、重试搜索或地图点选 | 地图点选后仍需逆编码核验 |
| 搜索上游失败 | 显示“地点搜索暂时不可用，已保留本次会话输入。可重试或改用地图选点。”，不伪装为空结果 | 重试或地图点选 | 本次请求未完成核验前不可保存 |
| 农村/地址不完整 | 地图点选或拖动图钉后请求逆编码；`MAPPED` 成功时显示适配器**建议展示地址**与行政目录路径相容状态，不强迫补齐未知门牌。建议地址不证明门牌正确 | 微调图钉、接受建议展示地址 | 规范化行政目录节点与所选 ServiceArea 节点路径相容；不表示实际服务范围、门牌或可达性已核验 |
| 适配器未配置/逆编码失败/不可映射 | 保留当前表单会话的输入、图钉和地图视图，分别显示“当前环境未配置已批准的位置核验服务”“位置核验暂时不可用”或“该位置无法映射到行政目录”；不伪装为空结果 | 重试、移动图钉或取消 | 不可保存；不得转入公共 OSM 端点 |
| 行政路径不相容 | 显示“图钉的行政路径与所选服务区域不相容，不能保存。”并展示所选目录路径与定位目录路径。地址文本仅为运营提示，绝不参与行政归属或保存判定 | 调整图钉/重新选 POI，或取消后选择正确服务区域重新开始 | 不可保存 |
| 地图瓦片或交互不可用 | 显示“地图暂时不可用，已保留本次填写内容。请重试或取消。”；地址 POI 成功也不能替代地图确认 | 重试加载地图或取消 | 新建、位置变更、INACTIVE→ACTIVE 不可保存/启用 |
| 疑似重复 | 展示同区域候选点位的名称、地址和距离；提示“请确认不是同一领取地点” | 返回调整，或明确“仍作为独立点位保存” | 仅在明确确认后保存；不自动合并 |

### 编辑与恢复

- **CONFIRMED（用户批准方向）**：编辑页默认展示已保存的服务区域、地址和图钉，服务区域只读；不因历史地址无法匹配目录而自动补选省市区、改区、重置图钉或覆盖地址。
- 触发矩阵：新建、**规范化地址改变**、以 6 位 GCJ-02 比较的纬度/经度改变和 INACTIVE→ACTIVE 进入完整定位与核验；仅编辑名称、营业时间、领取提示、容量，或状态不发生 INACTIVE→ACTIVE 转换时，不触发逆编码。客户端可更早提示变化，但服务端判定和持久化以 API 契约为准。
- 未触发 PATCH 即使携带规范化等价的地址原文或六位比较相等的坐标，API 也必须忽略这些位置字段、逐值保留原持久地址/坐标且跳过适配器；页面只提示“本次未变更位置，未重新核验”，绝不显示“历史位置待核验/已核验”。
- 本次表单会话仅在弹窗未关闭、未刷新或未离开页面时保留；不是持久草稿，也不承诺下次打开仍可恢复。
- **DEFAULT_ASSUMPTION**：同区域、按 DR-020 规范化的地址相同或图钉相距 50 米以内显示疑似重复提示。编辑时排除当前点位；确认继续不是删除、合并或迁移操作，首次候选与覆写均有审计。

### 固定文案与可访问性

- 地址输入标签为“详细地址或地点名称”；地图容器的可访问名称为“自提点地图，点击或拖动图钉选择实际位置”。状态文本以 `aria-live` 公告，不能只靠图钉颜色表达成功/失败。
- 主操作文字依状态使用“选择服务区域”“确认地图位置”“正在核验行政路径”“修正位置后保存”“仍作为独立点位保存”。禁止显示“已定位”而实际未完成路径核验，也禁止把路径相容描述为实际服务范围已验证。
- 错误与恢复必须保留当前文字、候选、图钉和已选服务区域；取消才丢弃未保存修改。

## Accessibility and responsive behavior

- Web 支持键盘焦点、表单 label、Alert live semantics、表格横向适配；移动小程序触控目标不小于常用按钮尺寸。
- 关键交互使用原生 button/switch/picker/input 或提供可访问名称和状态。
- 支持短/长商品名、空列表、错误、禁用和无权限状态；禁止只用颜色表达状态。
