# 多自提点购物车与统一结算（2026-09-24）

## 本轮决定与验收

- 用户确认 `prototypes/multi-pickup-cart-concept-20260924/` 的业务交互方向，要求直接开发。最新视觉决定：正式小程序保留现有 `pages/pickup-select` 白底“选择收货区域”页面结构和点位卡片，只从原型吸收多点位选项、可购优先与距离排序、当前选中态；不得照搬原型的红色整页样式。切换点位不清空既有购物车。
- 购物车按自提点、团期分组，展示各组商品和领取时间；可选择参与本次结算的组。
- 一次结算多个组：付款前逐组核对团期、价格、库存和固定自提点，显示各处领取安排；创建与库存预占全有全无。一笔真实支付关联多个独立订单，各订单各有提货码、履约与取消/退款状态。
- 支付回调、超时释放、重复提交及退款要有持久化幂等和金额约束；多张子订单退款累计不得超过原交易额。原型内的“模拟支付”仅用于交互演示，不是生产实现。
- 本轮不涉及大改版的页面沿用项目当前前端设计规范和组件风格；自提点页仅做现有页面的必要增量，购物车与结算页也不另起视觉语言。以原页面和候选页面同视口对照验收。
