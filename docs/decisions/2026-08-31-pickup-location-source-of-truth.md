# ADR — 自提点定位的单一事实来源与安全恢复

## 决定

- **CONFIRMED（用户批准方向）**：自提点的行政归属由 `PickupPoint.serviceAreaId → ServiceArea.regionCode → 行政区目录路径` 唯一决定。省、市、区只能显示这条链，不能与服务区域一起作为两个可冲突的保存事实。
- **DEFAULT_ASSUMPTION**：本 P1 迭代把每个 ServiceArea 表达为一个行政目录节点。逆地理结果只能证明其规范化目录节点与该节点路径相容；它不证明实际配送几何边界、门牌正确性、道路可达性或消费者可到达性。业务 ServiceArea 是否恒等于行政节点仍为 `BLOCKING_UNKNOWN`。
- **CONFIRMED（用户批准方向）**：地址/POI 搜索是输入首选；地图用于确认、拖动微调和地址搜索无结果时的兜底。仅在新建、位置变更或 INACTIVE→ACTIVE 时，由服务端以当场适配器结果完成行政路径核验；地址文字不能覆盖坐标核验得出的行政归属。
- **CONFIRMED（安全失败方向）**：适配器未配置、请求失败、地图不可用、行政标识不可映射或路径不相容时，保留本次表单会话并拒绝新建、位置变更和启用写入；不得转到未获批准的公共 OSM 端点，也不得把失败伪装成空搜索结果。
- **EVIDENCE_INFERRED**：当前地图坐标是 GCJ-02；现有高德适配器原样使用 GCJ-02，现有 OSM 回退在边界做 WGS84/GCJ-02 转换。因此后续接口/持久化仍以 GCJ-02 为统一坐标系；真实生产提供方及覆盖未获验证。
- **DEFAULT_ASSUMPTION**：同一服务区域、按 DR-020 规范化地址相同或 GCJ-02 Haversine 距离不超过 50 米为疑似重复。它只触发提示和明确确认，不自动合并、覆盖、删除或迁移点位。

## 当前证据与 Delta

| 现状证据 | 事实状态 | 风险 | 本轮冻结的最小 Delta |
|---|---|---|---|
| 管理端同时提交 `serviceAreaId` 和可编辑省/市/区；编辑时由地址反推地区 | EVIDENCE_INFERRED | 两套行政归属可冲突，历史地址可能静默换区 | 服务区域先选，目录路径只读；移除行政选择作为保存来源 |
| 创建/更新仅校验字段格式和服务区域存在，不验证坐标行政路径 | EVIDENCE_INFERRED | 可保存行政路径不相容的地图点；不等同于真实服务几何越界 | 写入边界逆编码 + 目录路径相容校验；不相容返回 409 |
| 搜索与逆编码调用失败会在地图组件中被吞掉 | EVIDENCE_INFERRED | 运营把不可用误认为无结果或已确认 | 区分未配置、提供方失败、不可映射和地图不可用；仅保留当前会话，失败零位置写入 |
| 既有编辑没有持久核验字段 | EVIDENCE_INFERRED | 不能可靠声明历史已/待核验 | 无状态触发矩阵：新建、地址/坐标变更、INACTIVE→ACTIVE 核验；其他编辑原样保留 |

## 备选方案与拒绝原因

1. **把省/市/区和服务区域一起持久化。**拒绝：创建第二行政事实源，不能解决冲突。
2. **仅信任地址字符串或浏览器回传的 adcode。**拒绝：可与图钉不一致，也不能作为服务端行政路径判断。
3. **未配置或失败时自动回退公共 OSM。**拒绝：没有获批准的生产提供方、条款、隐私、限流或目录映射证据；只能 fail-closed。
4. **逆编码失败时仍按运营手填经纬度保存。**拒绝：无法执行行政路径拒绝，且要求运营理解坐标。
5. **新增 POI ID、持久核验状态、地理围栏、路线规划或消费者实时定位。**拒绝：超出本轮定位配置的最小范围。

## 兼容、迁移与回滚

- **CONFIRMED**：既有 `serviceAreaId`、`address`、`latitude`、`longitude` 字段和公开 API 输出保持；没有数据库迁移、历史回填或外部 Key 采购。
- **CONFIRMED（方向）**：未变更地址/坐标、且未发生 INACTIVE→ACTIVE 的历史编辑不调用位置核验；历史值原样保留。系统没有持久核验状态，因此页面只可陈述本次请求是否触发核验。
- 回滚触发：若受控预发布表明已批准提供方不能稳定给出可映射乡镇位置，或安全拒绝造成不可接受的运营阻断，撤回尚未发布的 UI/适配器功能时仍必须保留 API 对新建、位置变更和 INACTIVE→ACTIVE 的 fail-closed 拒绝；不得回到可写入未核验坐标的旧行为。仅纯非位置编辑可继续。是否改用/采购提供方 Key 是 **BLOCKING_UNKNOWN**，需用户单独授权。

## 非目标

- 不采购、配置或调用真实生产高德 Key；不以本地 mock 当作真实覆盖证明；不把公共 OSM 端点作为未批准生产默认。
- 不做消费者实时定位、导航、路径规划、电子围栏、联系人采集、排班、照片审核或复杂地址治理。
