# 可配置岗位权限（2026-09-22）

用户授权：新增角色管理、权限管理，按菜单功能配置角色并分配员工；本轮允许 GPT-5.6 Sol 独立审核，替代不可用的 Luna。主会话唯一写入者，固定质量会话只读审核。

## 实现与边界

- 使用 Node-Casbin 校验已注册能力；员工业务身份和自提点范围保留，自定义角色另存 accessRoleId。平台角色与点位角色不得混合。
- 系统下分为员工管理、角色管理、权限管理和日志。角色支持新建、复制、编辑、停用和删除；删除已关联员工的角色会拒绝。预置角色可配置但不可删除。
- 权限管理展示已落地菜单/操作；角色页勾选权限。员工、角色、权限配置及紧急代办仍限定超级管理员，不能通过自定义权限绕过。
- 权限后端逐路由校验、未知能力拒绝；前端隐藏未获授权菜单和操作。商品编辑含上下架，对应原子商品保存接口。
- 角色修改与员工授权版本更新、会话撤销、审计写入同一 aggregate transaction；持锁后复查旧 actor 授权版本与角色版本。策略缓存按不可变版本与权限内容索引。
- 既有 JSON aggregate 向后兼容新增 accessRoles，不改历史交易或点位归属。没有实际角色数据时按预置角色解析。
