## 地址定位调查

- evidence-inferred：截图显示LOCATION服务未配置文案；服务端geo-search.ts依赖AMAP_WEB_KEY，缺少时返回LOCATION_VERIFICATION_NOT_CONFIGURED/503。地图瓦片可以显示不证明位置搜索或逆向校验可用。生产实际配置状态待运维只读核验。
- 运维只读实核：当前生产API容器AMAP_WEB_KEY不存在且非空=false；当前runtime及本机迁移准备runtime均无此键，已查旧家政env也未发现相应地图配置。因此已确认当前缺配置，现有证据不支持“迁移丢失了已有非空key”。ready五项依赖不包含地图，之前健康PASS不能证明地图能力可用。未输出凭据、调用地点提供方或修改服务器。
- evidence-inferred：pickup-location-picker.tsx输入后350ms查询候选，只在onSelect内提交候选坐标并逆向校验，输入本身不会自动移动地图。当前“输入地址后自动定位”提示与行为不符。
- prototype-default：自动查询、明确候选及定位状态；多结果要求选定，不凭同名街道猜坐标。单一明确结果可预览但保存仍须位置校验。
- 发现“重新检测”只递增searchRetry，而未定位时相同query仍可能被lastQueryRef去重挡住；待后续实施时用定向测试验证并修复，当前不改正式代码。
