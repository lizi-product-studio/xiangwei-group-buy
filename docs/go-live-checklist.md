# 上线验收清单

## 自动化门禁

- lint、typecheck、unit/integration tests、build 全部通过。
- MySQL 8.4 空库执行唯一基线迁移，第二次执行保持幂等。
- 两个独立 MySQL 连接可读到同一社区状态，Redis 队列健康。

- 退款故障注入覆盖事务提交后、外部退款提交前的中断：重启调和后每笔 `REFUNDING` 已付款订单只有一笔退款义务，并仅向支付机构提交一次。

## 运营验收

- 空库启动后不得自动写入“全国”区域、默认自提点、演示城市或演示订单。消费者只能看到已有真实启用自提点且允许下单的区域；未覆盖地区只能登记开通意向。运营显式创建区域、点位、商品、团期和运输信息。
- 团期开售后固定自提点不可变。
- 差异分配顺序可复算；运营确认前不得核销或退款。
- 使用五角色正反例复验到货：已授权 `PICKUP_MANAGER` 可逐商品正常/短少/破损确认且重复提交幂等；未授权点位负责人和 `OPERATOR` 被拒绝；`SUPER_ADMIN` 紧急代办必须填写原因。到货后正常数量可继续领取。
- 跨点位访问、重复/并发/分次核销、截止时刻核销、24 小时品质边界均被拒绝或正确处理。
- 员工停用、换角色、换点位后旧会话立即失效。
