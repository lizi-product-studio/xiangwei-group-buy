# 已开团商品图片同步修复

## 用户问题与根因

用户在后台给已开团商品补传图片，小程序首页仍显示“暂无图片”。线上商品 SKU 图片已保存且图片文件 HTTP 200，但消费者团期接口沿用开团时 imageUrl=null 的快照。

## 本轮范围

- 消费者团期列表和详情只对图片采用当前启用 SKU 的商品图片；目录停用过滤保持不变。
- 不改写团期、订单或价格快照，不变更库存、支付、履约和权限。
- 小程序首页、分类、详情、购物车、结算及订单的 product-image 绑定将空值转为空字符串，消除 String 属性接收 null 的警告。
- 覆盖开团后补图、换图、删图、停用隐藏，以及团期名称/价格/存储快照不变的回归。
