# 乡味集小程序参考布局原型

这是根据 2026-09-23 用户提供的三张参考截图制作的交互视觉稿，目标是让需求方先判断首页和“我的”页的布局方向。只借鉴布局、色彩节奏和信息层级；业务保持现有固定自提点、团期、订单、购物车与消息提醒。积分、优惠券、团长、供应商、直播与送货上门未加入原型。

直接打开 `index.html`，或在仓库根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，访问 `http://127.0.0.1:8765/prototypes/mini-reference-layout-20260923/`。

可交互项：首页分类、搜索和商品卡，商品详情与模拟加购，购物车，底部标签，“我的”页订单状态、自提点、消息提醒及其他服务入口。示例图片取自仓库已有原型和小程序资源；示例商品、订单、点位与日期不对应真实业务数据。原型不请求 API，不写入后端，不发起支付，也不代表小程序已改版。

待用户确认：参考图的红色顶部和三标签导航是否应用到正式小程序；目前分类入口在首页，原小程序独立“分类”标签可在落地时决定去留。
