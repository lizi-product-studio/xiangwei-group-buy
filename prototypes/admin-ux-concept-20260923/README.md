本目录是供用户确认视觉与交互规范的静态原型，不连接生产 API，不修改业务数据。

打开 `index.html`，或在仓库根目录运行 `python3 -m http.server 8771` 后访问 `http://127.0.0.1:8771/prototypes/admin-ux-concept-20260923/`。

可体验：订单筛选/重置/示意 CSV 导出/详情；用户搜索/详情中的完整联系电话；发货页的取消团期前置限制、正常登记和发车复核；菜单结构与设计规范；首次加载和刷新态。数据均为虚构示例。

待用户确认后，才可把此视觉与交互方案用于正式后台代码。展示用数字用户 ID 是方案，不是现有数据库实现。
