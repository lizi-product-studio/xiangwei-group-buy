## 后台覆盖

- 工作台：经营示例指标、待办→配送/售后/治理、履约进度。
- 商品：分类、规格、价格、库存、上架状态，新增表单与详情。
- 团期：固定点位、截单、订单进度、状态，草稿表单与团期规则。
- 订单：实付、领取进度、详情、领取记录及发车取消边界。
- 配送到货：批次、正常/破损数量、差异草案确认。
- 区域自提点：点位列表、搜索筛选、专用新增抽屉与演示保存。
- 售后异常：领取凭证、金额、受理意见，不直接执行退款。
- 运营治理：未授权通知/开通意向，缺合规渠道与结果凭证时保持待处理。
- 财务：退款义务、账本指标、固定退款单号，结果未知仅查询语义。
- 审计：操作者/角色/时间/动作/对象/结果，只读详情。
- 人员权限：角色、点位范围、状态与停用前确认。
- 点位工作台：仅本点到货与取货，6位码和本次领取数量。

角色可见菜单沿现有 navigation.ts：运营8模块、客服3模块、财务2模块、超管11模块；点位负责人仅本点工作台，超管不会自动切入点位负责人视图。页面索引可显式切到对应角色用于评审。

所有列表有本地搜索、状态筛选、清空结果状态、详情抽屉或表单。普通业务确认弹窗仅演示确认反馈，不实现真实持久化和后端状态机；新增自提点示例保存至内存表格。

## 点位位置流程

服务区域→名称/地址→候选列表→位置示意与只读演示GCJ-02→行政路径相容说明→营业时间/领取提示→固定底部保存。

- 未配置：默认；地点搜索及保存阻断，有配置说明。
- 定位中：等待状态，保存阻断。
- 多个候选：用户选择实际地点，未选不可保存。
- 失败：输入保留，单条就近错误与重试，保存阻断。
- 已确认：明确的原型模拟状态；选点后才能示范保存。
- 修改地址会清除旧确认；模拟微调会重新进入校验中。

原型没有伪造地图底图。用明确标注的位置确认示意容器和现有定位图标展示步骤，坐标为示例。真实底图、地址搜索和服务端逆地理校验是不同能力；本原型不声称已配置或可在真实系统保存。坐标路径相容不证明实际配送范围、门牌或通行性。
