# 乡味集社区拼团系统（统一静态原型）

2026-09-14 优化预览版：从远端 `cd9ed435` 的静态原型复制修订，原始快照保留。先打开 `index.html` 选择后台或小程序；原型通过用户确认后才映射到真实应用。详细规范见仓库 `docs/design-system-v2-preview.md`。

本目录把「乡味集」社区拼团系统的两个独立静态原型集中到一起，便于从消费者下单到平台运营、履约和售后查看完整业务闭环。

## 两个入口

- `admin/index.html`：运营管理后台原型，供超级管理员、运营、客服、财务和点位负责人使用。
- `miniprogram/index.html`：消费者端交互原型，以网页形式模拟微信小程序界面。

两个入口各自保留原有的 `app.js`、`styles.css` 和相对资源路径；消费者端图片位于 `miniprogram/assets/`。

## 系统覆盖范围

消费者端覆盖选择区域与固定自提点、浏览团购商品、加入购物车、确认订单、模拟支付、查看成团与配送状态、出示取货码、确认领取、申请售后及查看退款进度。

管理后台按角色覆盖以下工作：

- 超级管理员：员工、角色权限、操作日志和通知管理等系统能力。
- 运营：商品、分类、团期、订单、区域、自提点及总部履约管理。
- 客服：消费者问题、取消申请和品质售后受理。
- 财务：退款待办、退款记录和账务流水。
- 点位负责人：本点到货确认、领取核销、核销记录和本点团期查看。

典型业务闭环为：消费者选择自提点并参加团购 → 提交订单和模拟支付 → 平台截单并判断是否成团 → 总部发货 → 自提点确认到货和核销领取 → 异常订单进入客服、运营和财务协作的售后退款流程。后台还提供订阅通知和操作审计的演示界面。

## 运行方式

可以直接使用浏览器分别打开 `admin/index.html` 和 `miniprogram/index.html`。

也可以在本目录启动任意静态文件服务器。例如：

```powershell
python -m http.server 8080
```

随后访问：

- `http://localhost:8080/admin/`
- `http://localhost:8080/miniprogram/`

## 预览检查

`verify.mjs` 使用 Playwright Chromium 检查 33 个小程序页面在 320/375/390/430px 下的布局、后台五种角色菜单及 375–1440px 布局。先启动静态服务器，再设置 `PROTOTYPE_URL` 和仓库外的 `PROTOTYPE_EVIDENCE_DIR` 运行 `node verify.mjs`。已有 Playwright 安装可用 `PROTOTYPE_PLAYWRIGHT_PATH` 指向其模块路径；截图与检查结果只写证据目录，不进入源代码仓库。

预览中的后台角色与列表状态在页面顶部切换；小程序设备外的“演示控制”可切换宽度和登录/页面/提醒结果。后台使用任意非空演示账号和密码。请勿填写真实凭据。

## 使用边界

本目录仅用于产品演示和交互评审。它是纯 HTML、CSS、JavaScript 与本地图片组成的静态原型，演示数据直接写在脚本中；页面操作不会连接生产数据库或后端 API，刷新页面后可能恢复预置状态。

其中的微信登录、支付、退款、订阅通知、权限控制和履约状态均为界面或流程模拟，不代表真实微信小程序、生产管理后台、后端服务或正式渠道已经实现、接入或通过验收。请勿将本原型用于真实交易或生产运营。
