# 商品内容、销量、订阅与自提点照片 · 待确认原型

本目录仅为交互原型，不连接生产 API，不写入业务数据，不代表功能已上线。浏览器刷新后恢复初始示例。复用的商品/点位图片来自既有原型 assets，仅为演示素材，不作为真实商家实景。

打开 `index.html`，或从 prototypes 目录启动静态服务后访问 `/product-content-concept-20260922/`。宽屏后台与小程序并排，窄屏依次展示。页面顶部可切换商品管理/自提点管理。

## 需求与原型

- 商品图片：最多5张，本地多选上传、删除、前后排序；第一张为封面，小程序详情可切换、触摸滑动、点击放大。
- 商品介绍：主表单新增独立300字介绍，小程序详情完整展示，首页摘要。计价单位移到“其他设置”，保留订单/履约含义，不将既有 skuName 当成长文本覆盖。
- 详情配置：最多10张详情长图，每张10MB以内，排序/删除/查看；小程序底部按原比例连续展示。没有图片则隐藏区域。该数量与容量上限是待确认方案。
- 销量：后台只读示例136件已支付、8件成功退款、128件净销量；小程序已售128件。建议跨团期、按购买数量统计，不按订单数，不提供虚构销量输入。正式退款计数仍需实现时核对现有商品行与退款数量契约。
- 订阅：首页未订阅持续提示、不自动弹窗；五类现有通知分批3+2，由用户主动触发授权。支持部分订阅、拒绝、次数用完、关闭提醒、未登录情景。管理入口为“我的 → 消息提醒”。系统关闭与微信授权撤销明确区分，原型不操作真实微信授权。状态判断在实现时需结合后端订阅记录与微信允许读取的授权状态，不能承诺永久有效。
- 自提点照片：独立新建/编辑页面，新增必须一张照片；缺照片时给中性占位；保存演示后在首页、商品、自提点详情及我的统一展示。既有绑定与订单规则不变。

## 建议确认的默认规则

介绍300字；商品图5张/每张5MB；详情图10张/每张10MB；自提点照片1张/5MB；真实净销量口径。商品介绍及照片更新用于当前商品展示，历史订单规格与金额仍保留历史快照。

## 评审路径

1. 商品管理上传图片或添加示例图，移动到首张；右侧商品切换图片。
2. 修改介绍，观察字数与预览；滚动手机内部至底部查看长图与售后说明。
3. 右侧首页点击订阅，模拟允许前3类，再点击继续订阅剩余2类；进入我的→消息提醒关闭。
4. 订阅状态下拉框演示拒绝后重试、未登录、部分订阅和需再次订阅。
5. 自提点管理→新增，自提点无照片时保存被阻止；补齐照片/名称/地址保存，切换小程序各页面观察。

范围外按钮如购买、导航、拨号仅提示演示，不执行真实操作。原型中示例长图的售后文字不是正式业务承诺。
