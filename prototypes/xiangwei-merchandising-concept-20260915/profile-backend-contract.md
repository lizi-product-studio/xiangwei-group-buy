# 消费者个人资料后端设计建议

状态：已实现。本文记录消费者资料接口、数据和隐私边界；生产发布状态以对应发布证据为准。

## 1. 当前事实

现有消费者 `User` 只包含 `id`、微信 `openId`、已验证手机号、手机号验证时间、账号状态和创建时间。退出接口 `POST /api/v1/auth/logout` 已存在，并会撤销当前访问令牌。当前没有消费者姓名、头像、个人资料查询或资料编辑接口。

## 2. 数据模型

在消费者用户对象增加以下字段：

| 字段 | 类型 | 规则 |
|---|---|---|
| `displayName` | `string | null` | 1–30 个字符；去除首尾空格和控制字符；用于个人资料展示 |
| `avatarUrl` | `string | null` | 只保存平台内部受保护头像资源地址，不接受任意外部 URL |
| `profileUpdatedAt` | ISO 时间 | 资料最后更新时间 |
| `profileVersion` | 正整数 | 乐观并发控制，避免两台设备互相覆盖 |

手机号继续沿用 `phoneNumber` 与 `phoneVerifiedAt`，不放进普通资料更新请求。

## 3. 消费者接口

### `GET /api/v1/me/profile`

只读取当前登录用户，不接受客户端传入 `userId`。

```json
{
  "data": {
    "displayName": "栗子",
    "avatarUrl": "/api/v1/profile-images/example.webp",
    "phoneNumber": "138****8000",
    "profileVersion": 3,
    "updatedAt": "2026-09-15T10:00:00.000Z"
  }
}
```

### `POST /api/v1/me/profile`

仅允许修改姓名和已上传头像引用。

```json
{
  "displayName": "栗子",
  "avatarUrl": "/api/v1/profile-images/example.webp",
  "expectedVersion": 3
}
```

版本不一致返回 `409 CONCURRENT_MODIFICATION`，客户端提示刷新后重试。接口不得接受手机号、微信 `openId`、账号状态或角色字段；服务端同时保留 PATCH 兼容入口。

### `POST /api/v1/me/profile-image`

接收当前登录用户上传的 JPG/PNG/WebP，限制大小和像素，复用现有图片转码能力生成内部 WebP，移除图片元数据。头像保存在商品图片目录的隔离子目录，读取时校验当前登录用户及其头像引用，并返回 `private, no-store`；上传入口采用用户级限流。

### `POST /api/v1/me/phone/rebind`

请求体只包含微信 `getPhoneNumber` 返回的一次性 `phoneCode` 和 `expectedVersion`。服务端向微信换取手机号并校验 `appid`、时间戳和号码格式，不能接受客户端直接提交的明文手机号。成功后更新 `phoneNumber`、`phoneVerifiedAt` 和资料版本；失败保留原手机号。

手机号是订单联系和登录绑定信息。更换后，历史订单快照保持原下单联系人信息；新订单使用新号码。是否允许同一手机号绑定多个微信账号应在开发前确定并建立对应唯一性规则，不能在冲突时自动合并账号。

### `POST /api/v1/auth/logout`

沿用现有接口。成功返回 `204`，撤销当前令牌。客户端应先清除当前设备会话，再回到未登录状态；退出不会删除用户、订单、取货码或固定自提点。

## 4. 权限、隐私和审计

- 所有资料接口只允许 `USER` 访问本人数据，用户身份来自访问令牌。
- API 返回掩码手机号；只有手机号验证交换逻辑可以接触完整号码。
- 日志不得记录微信 `openId`、完整手机号、`phoneCode` 或头像原文件。
- 姓名和头像更新记录操作时间及用户 ID；手机号更换单独记录安全事件，但只保留掩码结果。
- 退出、保存资料和手机号更换均需防重复提交；头像上传失败不得清空原头像。
- 现有用户升级后字段默认为空，界面回退为“微信用户”和默认头像，不要求批量补数据。

## 5. 小程序交互

- “编辑资料”可修改头像和姓名。
- 手机号只显示掩码和“更换手机号”，点击后调用微信手机号授权组件。
- 保存资料失败时保留输入并提供重试。
- 点击“退出登录”先说明只退出当前设备，经确认后撤销会话；完成后隐藏订单、取货码和个人资料。
