# 乡味集首页陈列与轮播配置原型

本原型是 2026-09-15 已确认的新版小程序视觉与交互基准；`apps/` 已按该方向实现，原型仍使用静态演示数据。

## 评审范围

- 小程序首页：固定自提点、搜索、自动轮播、分类快速筛选、团期摘要和横向商品卡。
- 小程序分类页：左侧完整分类目录和右侧商品列表。
- 小程序“我的”：个人信息、订单快捷入口、固定自提点，以及采用统一双列功能卡的常用服务和账号设置。
- 运营后台：首页轮播列表、状态、投放范围、时间、跳转、排序及编辑表单。
- 账号资料：头像和姓名编辑、已验证手机号更换入口、退出登录确认及未登录状态。

参考图仅用于提取暖色氛围、高信息密度商品陈列和分类结构。没有引入当前乡味集业务不存在的团长、优惠券、积分商城或购买头像墙。

## 交互

- 左侧可切换小程序首页、分类页、“我的”和后台轮播页面。
- 首页轮播每 4.5 秒自动切换，也可点击圆点切换。
- 首页横向分类和分类页左侧目录可筛选商品。
- “加入购物车”、分享、刷新等提供本地反馈。
- 分类页商品使用带文字的“加入购物车”按钮，避免只有加号造成理解成本。
- “我的”页面可打开个人资料编辑、模拟更换手机号并确认退出登录。
- 后台“新增轮播”“编辑”打开配置弹窗，“预览首页”返回消费者首页。

消费者资料的数据模型、接口和隐私边界见 `profile-backend-contract.md`，相应 API 与小程序页面已实现。

直接打开 `index.html` 即可预览；也可在本目录运行静态文件服务。
